# LinkedIn draft

I let Claude Code build five live websites while I did other things: 215 pages, 2,125 passing tests, 464 commits.

The lesson wasn't "AI can code overnight". It was that unattended work needs a referee. In my setup the agent can't declare itself done; the tests do. A second agent reviews every change. Runs can't overlap, can't exceed a budget, and ask for help in a file when stuck.

I've open-sourced the method and tooling as Compounding Loop: a CLI, templates, a local dashboard and a Claude Code plugin. MIT licensed, no telemetry.

https://github.com/Minntooos/compounding-loop
