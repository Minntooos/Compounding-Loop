In a locked-down sandbox `npx playwright install chromium` can fail. Do not retry it. Point the config at a preinstalled Chromium or a system Chrome, and if Chrome then fails over missing libraries, run `npx playwright install-deps chromium`. Record the working setup in the project's Commands section once.
