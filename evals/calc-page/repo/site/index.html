Tiny Calculators

Welcome to a tiny calculator site. It collects small, tested tools that answer one question each. Pick a calculator below to begin. Every formula is a plain function with unit tests, and every page is checked for a title, a description, a canonical link and a place in the sitemap before it is published. New tools are added over time, so check back. Nothing here needs an account, a login or any personal details, and nothing is stored on a server. Each page explains how to use the tool, how the number is worked out, and shows a worked example so you can see whether the answer makes sense before you rely on it for anything that matters to you.
